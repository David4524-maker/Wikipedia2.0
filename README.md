# Wikipedia 2.0

Wikipedia 2.0 es una versión "mejorada" de Wikipedia normal usando la librería **WikiEngine.js**

> Ojo, Wikipedia 2.0 puede enfrentarse a CORS que es parte de la seguridad del navegador y los CORS pueden bloquear esos resultados, por eso te recomiendo que vallas al sitio oficial del [Wikipedia normal](https://www.wikipedia.org)

## Características nuevas

- Nuevos resultados (Estan en el apartado "Solo en Wikipedia 2.0")

- Mas idiomas

- Interfaz diferente

- Botón "Leer articulo completo"

> Este proyecto tampoco esta diseñado para competir con Wikipedia normal, de echo te conte que tenia un boton para ver todo donde te lleva a Wikipedia normal

## ¿Cómo se traducen cada cosa?

Las traducciones no se escribieron a mano, se usa **MyMemory**

## ¿Cuando usar Wikipedia 2.0 y Wikipedia normal?

A ver, no es obligatorio usar Wikipedia 2.0, pero aquí va

| Wikipedia 2.0 | Wikipedia normal
| :--- | ---: |
| Quieres una respuesta rápida | Necesitas el artículo completo  |
| Quieres explorar sin rumbo | Estás estudiando, escribiendo un trabajo o citando una fuente | 
| Quieres escuchar el artículo en voz alta, usar el modo oscuro o compartir el enlace con un botón | Quieres ver quién editó algo, el historial de cambios o las páginas de discusión |
| Necesitas cambiar de idioma con un clic y que la interfaz cambie también | Quieres editar o corregir un artículo, o crear una cuenta |
| Quieres mas resultados | Buscas categorías, listas o artículos relacionados de forma organizada |
| Quieres volver a algo que buscaste con el historial de búsquedas recientes | Necesitas datos muy actuales o de temas delicados, donde conviene leer la versión completa y su historial |

> AVISO: En la sección "Solo en Wikipedia 2.0" no son resultados del Wikipedia normal, y de traductor se usa MyMemory, y puede cometer errores de traduccion
